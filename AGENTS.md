# Project Rules & Workflows

## Auto-Push to GitHub
- **Immediate Push**: Every time code, markup, styles, scripts, or assets are modified or added in this project, automatically stage, commit, and push directly to GitHub (`origin/main`).
- **Zero Prompts Needed**: Never wait for the user to request or remind to push. It must happen proactively at the end of every task or change set.
- **Commit Standards**: Use clean conventional commits (`feat(...)`, `fix(...)`, `style(...)`, `chore(...)`) with concise descriptions.
